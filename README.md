# Artificial Intelligence Course

**Instructor:** Srinivasa Sai Chava · Boston University

Course materials for the Artificial Intelligence & Data Science programme — slides, teaching
notebooks and practice sets, published session by session.

**Covered so far: Day 1 – Day 8** (Python Basics · OOP)

---

## How the sessions run

| | |
|---|---|
| **Format** | 90 minutes concepts and live coding, then 30 minutes hands-on practice |
| **Environment** | Google Colab — nothing to install |

Each session ships with four things:

1. **Slides** (`.pptx` and `.pdf`) — what we work through together in class
2. **Teaching notebook** — every example from the slides, runnable, with extra detail
3. **Practice questions** — the 30-minute hands-on set
4. **Practice solutions** — worked answers with explanations, **posted after the session**

## Working with the notebooks

**Open in Colab** — click any badge above. Colab loads the notebook straight from this
repository; nothing is installed and nothing is downloaded.

**Save your own copy before you start working.** In Colab: `File → Save a copy in Drive`.
Otherwise your edits are lost when the tab closes.

**Run every cell yourself.** Reading a notebook teaches you far less than running it,
changing a value, breaking a line on purpose and reading the error. The teaching notebooks
are written to be edited.

## Homework set so far

**Day 1** — rebuild the result calculator using `input()` with `try` / `except` ·
write a tip calculator (bill, tip %, people → per-person amount)

**Day 2** — extend the guessing game with a hot/cold hint · print a centred star pyramid
of height `n` · sum every third number from 1 to 100

**Day 3** — rewrite the guessing game using three functions · write
`is_valid_email(text)` returning `True` / `False` · add docstrings to everything

**Day 4** — write `remove_duplicates(items)` that keeps the original order · given two
lists, print the items in both, in either, and in only one · rotate a list by `n` positions
using slicing

**Day 5** — count how many times each letter appears in a sentence · invert a dictionary
so the values become keys · extend the gradebook with a `top_student()` function

**Day 6** — rewrite three loops from Days 2–5 as comprehensions · build `{word: length}`
for a sentence · find one comprehension that is worse than its loop, and explain why

**Day 7** — write a `Book` class with a `summary()` method and `__str__` · rewrite Day 5's
gradebook as a `Gradebook` class with `add_mark()` and `top_student()`

**Day 8** — build a `Shape` parent with `Circle` and `Square` children · extend Day 7's
`BankAccount` into a `SavingsAccount` that adds interest · find one place where inheritance
would be the wrong choice
